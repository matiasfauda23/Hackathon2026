# 🌍 HuellaIA

**Pabellón:** 4. Decisiones Exageradas
**Ingrediente improbable:** Número absurdamente preciso

## Ficha del invento

| Campo | Descripción |
|---|---|
| Nombre | HuellaIA |
| Pabellón | Decisiones Exageradas |
| Quién | Programadores y estudiantes que le hacen decenas de consultas por día a una IA |
| Problema | Nadie sabe cuántos recursos del planeta consume cada consulta a una IA |
| Entrada | El texto de la consulta |
| Proceso | Calcula el impacto según el largo de la consulta y simula la destrucción del planeta |
| Salida | Un planeta 3D que se destruye en vivo y un informe con cifras absurdamente precisas |
| Ingrediente | Número absurdamente preciso |
